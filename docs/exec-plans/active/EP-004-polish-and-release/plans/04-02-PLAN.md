# Plan 04-02：PR 规范门禁

作者：glm5.1+37chengshan

## objective
对 PR 标题、描述进行规范化门禁，提升评审质量与追踪性。

## tasks
1. 新建 `pr-hygiene.yml`。
2. 校验 PR 标题符合 Conventional Commits 前缀（feat/fix/chore/docs/refactor/test/perf/ci）。
3. 校验 PR 描述包含最小字段契约：变更摘要、验证步骤、风险与回滚。
4. 新建 `.github/pull_request_template.md`。
5. 固定检查名为 `PR Hygiene / title-and-body-check` 并写入治理文档。

## acceptance_criteria
- AC-04-02-1：不符合标题规范时 PR 检查失败。
- AC-04-02-2：描述缺失关键段落时 PR 检查失败。
- AC-04-02-3：PR 页面自动加载模板，且模板覆盖“变更摘要/验证步骤/风险与回滚”。
- AC-04-02-4：检查名固定为 `PR Hygiene / title-and-body-check`。

## verify
1. 语法与注册检查：`gh workflow view pr-hygiene.yml`。
2. 负样例验证：创建草稿 PR 使用非法标题，执行 `gh pr checks <PR_NUMBER> --watch`，确认 `PR Hygiene / title-and-body-check` 失败。
3. 负样例验证：保留合法标题但删除描述关键段落，确认检查失败。
4. 正样例验证：修复标题与描述后，确认检查通过。
