# Plan 04-04：分支保护与治理文档

作者：glm5.1+37chengshan

## objective
提供 main 分支保护的一键脚本与维护文档，完成完整 GitHub 工作流闭环。

## tasks
1. 新建 `script/setup_branch_protection.sh`（基于 `gh api`）。
2. 新建 `.github/CODEOWNERS`。
3. 在脚本中显式配置 required checks：`PR Gate / build-and-test`、`PR Gate / artifact-guard`、`PR Hygiene / title-and-body-check`。
4. 在脚本中配置最小审查规则：至少 1 个审批、dismiss stale reviews、禁止强推与删除分支。
5. 新建 `docs/GitHub工作流与门禁说明.md`，说明门禁、发布、分支策略、故障排查。

## acceptance_criteria
- AC-04-04-1：脚本可配置 `main` 保护（required checks 与计划定义一致、禁止强推、禁止删除）。
- AC-04-04-2：脚本支持 `--dry-run` 与 `--apply` 两种模式，且具备幂等性。
- AC-04-04-3：文档完整覆盖“开发 -> PR -> 合并 -> 发布”流程。
- AC-04-04-4：CODEOWNERS 生效并可审阅责任清晰。

## verify
1. `bash script/setup_branch_protection.sh --dry-run`。
2. `bash script/setup_branch_protection.sh --apply`（有权限时）。
3. `gh api repos/<owner>/<repo>/branches/main/protection`，确认 required checks 与 review 规则与脚本一致。
4. 以测试 PR 验证 required checks 未通过时不可合并。
5. 无管理员权限时，至少执行只读校验：`gh api repos/<owner>/<repo>/branches/main/protection || true` 并在文档记录权限限制。
