# Plan 04-03：发布分发流水线

作者：glm5.1+37chengshan

## objective
实现 tag 驱动的发布分发流水线，为公开测试打包交付提供自动化基础。

## tasks
1. 新建 `release-distribution.yml`（触发 `v*` tag 与 `workflow_dispatch`）。
2. 在流水线中执行构建与测试。
3. 生成应用压缩包作为 Artifact。
4. 通过 GitHub Release 上传产物。
5. 明确 `permissions`（`contents: write`）与失败路径（无 tag/无权限时失败信息）。

## acceptance_criteria
- AC-04-03-1：创建 `v*` tag 时可触发发布流水线。
- AC-04-03-2：流水线能产出可下载 Artifact。
- AC-04-03-3：流水线失败时能给出可定位日志。

## verify
1. 语法与注册检查：`gh workflow view release-distribution.yml`。
2. 手动触发验证：`gh workflow run release-distribution.yml`，随后 `gh run list --workflow release-distribution.yml --limit 5`。
3. tag 触发验证：创建测试 tag（如 `v0.0.0-rc1`）并推送，确认流水线运行并生成 artifact。
4. 发布产物验证：`gh release view <TAG>`，确认包含预期文件。
